# Project Rules

- This project is a web-first alpha.
- Use Phaser + TypeScript + Vite for the browser runtime.
- Do not add React, Vue, Svelte, or a backend.
- Do not use Unity runtime.
- Prefer data-driven content stored as typed data or public content files.
- Keep TypeScript strict and explicit.
- Build small, isolated modules with narrow responsibilities.
- Do not use `any` unless there is no practical alternative; document the reason when it is used.
- Do not add paid or external services inside the runtime.
- Do not add Firebase, analytics SDKs, microphone access, or speech recognition.
- Minimize dependencies.
